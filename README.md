# Портфолио Юлии Шайфеле

Статический сайт, написанный с нуля на HTML, CSS и JavaScript, без конструкторов и сборщиков.

Два проекта: AKAI Force и ePsyLive. Шрифты и изображения включены в репозиторий; внешние CDN не требуются.

Запуск: откройте index.html или выполните `python -m http.server 4173`.

Публикация: GitHub Pages, ветка main, корневая папка.

В saved-sections сохранён отключённый блок процесса работы; на странице он не отображается.
